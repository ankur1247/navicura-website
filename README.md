# Navicura Lifescience Website

A responsive, dependency-free corporate website for **Navicura Lifescience**.

## Included

- GMP and pharmaceutical quality compliance services
- Audits and inspection-readiness support
- Training and knowledge-platform activities
- Regulatory, export and commercial support
- NaviAudit and NaviDesk digital solutions
- Approved Navicura brand artwork
- Responsive navigation, accessibility basics and subtle motion

## Preview locally

Open `index.html` directly, or run a simple local server:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

GitHub will provide a Pages URL after deployment.

## Custom domain: Navicura.in

After the domain’s DNS is configured for GitHub Pages:

1. In **Settings → Pages**, enter `Navicura.in` under **Custom domain**.
2. Enable **Enforce HTTPS** after GitHub completes its certificate check.
3. Add a file named `CNAME` containing only `Navicura.in` if GitHub does not create it automatically.

## Editing

- Main content: `index.html`
- Styling: `assets/css/styles.css`
- Interactions: `assets/js/main.js`
- Images: `assets/images/`

No build command, framework or external font service is required.
